Handwriting that feels like paper. An agent that answers in ink.

Write with a pen on a phone, tablet or laptop. Inkwright reads your handwriting, connects it to everything you've written, checks it against itself and writes back on the page. Your notes stay as plain files on your own devices.

write

Ink under the nib before the next frame.

Strokes are drawn from raw pen events with prediction. On Android a native ink tip paints the newest milliseconds straight to the screen.

  • Scribble to erase. It caught 99.6 % of 250 test scribbles and erased none of 330 normal strokes.
  • Paper you can hear and feel. Nib sound that follows speed and pressure, and haptic grain on Android.
  • Every page. Ruled, dot, Cornell, music and planner paper, and any PDF to fill in and sign.
  • Studio tools. Calligraphy nib, tape, sticky notes, layers, spreads and locked notes.
think

An AI that works on the page, not in a sidebar.

Use OpenAI, Claude, Gemini, OpenRouter, Ollama or any compatible server, or the on-device models that run on your phone's or laptop's GPU and send nothing anywhere.

Answers in ink

Lasso a question and the answer is written beside it in handwriting, in a colour that is never mistaken for yours. One undo removes it.

Sketch it, run it

Draw boxes and arrows and press Run. Each box becomes a step: fetch, filter, sum, chart, or ask the AI. Results land beside each box.

A wiki that cites

Your notes are compiled into linked pages. Each sentence is tagged extracted, inferred or ambiguous and points to the exact spot on the page it came from.

A linter for your thinking

It notices when Tuesday's note says "under 50 ms" and Friday's says "averages 110 ms", and shows you both.

Notes that listen

Lectures are transcribed on the device. Tap any stroke to hear what was being said while you wrote it.

Study

FSRS flashcards from any note, and a teach-it-back tutor that quizzes you and finds the gaps.

trust

Every AI call passes one checkpoint.

  • Routing by policy. Mark a notebook hidden, read-only or "never leaves this device".
  • Privacy firewall. Emails, phone numbers, cards and keys are replaced before the model sees them, then put back in the answer.
  • About 80 % fewer tokens from shortening context reversibly, with spend shown in dollars.
  • Signed audit trail that you can verify offline. Agents can run in dry-run mode, proposing changes for you to approve.
  • For teams: an air-gapped Docker appliance, a managed policy file, an SBOM and retention with legal hold.

build

Your notebook is a server for your other tools.

MCP (spec 2026-07-28), A2A, a REST API with OpenAPI 3.1, signed webhooks, a typed SDK, a CLI and an Agent Skill. Notes can link to functions in your code and are flagged when the code drifts.

# Give Claude Code your notebook
claude mcp add inkwright -- node apps/mcp-server/dist/index.js \
  --vault ~/Notes --read-only

# Or call it like any web API
curl -H "Authorization: Bearer $KEY" \
  "localhost:8765/api/v1/search?q=latency&mode=hybrid"

# Fail CI when docs drift from code
npx inkwright drift ~/Notes --check

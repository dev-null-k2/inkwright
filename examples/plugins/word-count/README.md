# Word count & reading time

An example Inkwright plugin that shows every kind of contribution a plugin can make:

| Contribution | What it does |
| --- | --- |
| Panel `stats` | Words, characters and reading time of the open note, and of the selection, live |
| Command `count` | ••• › Plugins › Count words in this note (and the search palette): a toast with the numbers |
| AI tool `reading_time` | The assistant can ask how long a note takes to read |
| Exporter `plain-text` | Export › Plain text: the note's typed text and recognized handwriting as .txt |
| Setting `wordsPerMinute` | Reading speed, in Settings › Plugins |

Permissions: read notes, see the open note and selection, know when notes change, give the
assistant a tool. No network.

Install it from Settings › Plugins › Browse (it is in the curated list), or from this folder with
"Install from a folder".

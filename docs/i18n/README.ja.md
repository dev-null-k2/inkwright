## なぜ作ったのか

紙はいまでも最高の思考の道具です。けれどもノートアプリは、紙のように書けても何も理解しないか、何でも理解しても書き心地はフォーム入力のようなものばかり。そして「サイドバーの AI」は、ノートについての質問ひとつのために、ノート全体を誰かのサーバーへ送ってしまいます。

Inkwright はペンから始まります。インクは次のフレームより先にペン先の下に現れ、ぐしゃぐしゃと書けば消え、紙をなでるペン先の音がし、Android では紙の質感まで指に伝わります。そのページに「考える力」を与えます。手書きを読み、これまで書いたすべてとつなげ、矛盾がないか確かめ、あなたの字とは明らかに違う「AI のインク」でページに答えを書き込むエージェントです。ノートはあなたのデバイスとストレージに普通のファイルとして残り、AI のすることはすべて見える・出典がある・元に戻せる、を守ります。

## できること

- **書く**：遅延の少ないインク（Android ではネイティブのペン先描画）、紙の音と触感、ぐしゃぐしゃ消し（580 ケースで 99.6% を検出し、普通の文字は一度も消さない）、万年筆・カリグラフィー・鉛筆・蛍光ペン、PDF への記入と署名。
- **考える**：OpenAI、Claude、Gemini、Ollama などどんなモデルでも、あるいは端末上のローカルモデルでも（データは端末から出ません）。質問を投げ縄で囲むと、AI が手書きで横に答えます。箱と矢印を描けば、そのまま「実行」できます。講義は端末上で文字起こしされ、インクをタップするとその時の音声が流れます。
- **覚える**：ノートから自動で編まれる個人 Wiki（各文に「抽出・推論・あいまい」のタグと出典位置）、矛盾チェック、FSRS フラッシュカード、双方向リンク、デイリーノート、3D グラフ、Obsidian との相互変換。
- **信頼**：すべての AI 呼び出しが一つの関門を通ります。ポリシーによるルーティング、個人情報のマスキング、コンテキスト圧縮（約 80% のトークン削減）、コスト計測、署名付き監査ログ。ノートブックごとに「この端末から出さない」も設定できます。
- **開発者向け**：`[[code:パス#関数]]` でノートをコードにリンクし、シグネチャが変わると「ずれ」を通知。検証済みのアーキテクチャ図、実行できるランブック、MCP・A2A・REST API（OpenAPI 3.1）・Webhook・SDK・CLI。

## はじめる

```sh
git clone https://github.com/karthikkasukurti/inkwright && cd inkwright
npm install
npm run dev
```
